# Backlog

This list consolidates unresolved decisions, requested features and validation gaps. No priority, delivery date or implementation approval is implied. Those investigation results are separate from subsequent approvals: AU-1 MP2 implementation is now selected; EPG stays Deferred. LP-1 live controls are approved and implemented locally; MR-1 memory sharing is approved and implemented locally; runtime/audio/physical acceptance remains separate.
